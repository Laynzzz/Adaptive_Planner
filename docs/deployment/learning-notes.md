# Delivery and observability learning notes

This supplement explains the choices behind Tasks17–18; the main teaching guide introduces the whole application.

OpenTelemetry gives traces and metrics a common API and export format. A trace connects one request with the later job/provider work; metrics summarize many operations without identifying owners. The API stores a minimal trace-parent string in the same database transaction as durable work. After commit, a worker restores that context. An in-memory parent would disappear across processes, and a context committed before a rolled-back job would misrepresent accepted work. Manual instrumentation was chosen over broad automatic instrumentation so secret-bearing OAuth queries, SQL arguments and provider bodies never become telemetry. Local Prometheus/Grafana make the exported measurements inspectable; CloudWatch/X-Ray are only prepared cloud destinations.

A sampled trace is diagnostic evidence, not the queue's source of truth. PostgreSQL owns job states, deadlines and fencing tokens. Killing a process proves crash behavior; advancing an injected clock proves lease-boundary logic without measuring real elapsed recovery time. Both facts must be stated separately. Metric labels use bounded classifications because an owner/job UUID per series can leak identity and create an expensive unbounded metric bill.

The Docker build separates Node compilation and Python dependency installation from runtime. One digest identifies the exact artifact used by API and workers. The frontend is served by the API after its routes, making the deployed browser/API origin identical. UID10001 and a read-only root reduce accidental writes; an explicit ephemeral scratch volume supports solver child files. The short cloud init container changes only that volume's permissions. It does not run the application as root.

Terraform describes a reviewable AWS resource graph. `validate` checks configuration and provider schemas; a mocked `terraform test` checks expressions and intended guards. Neither proves IAM permissions, regional capacity, Cognito selectors or a successful deployment. State contains generated secrets even when terminal output redacts them, so a separate encrypted/versioned/restricted backend is required. Budgets send alerts; they cannot enforce a hard spending ceiling.

A healthy ECS service is not proof of the selected release. The circuit breaker may have restored another task definition while the service becomes stable. The release helper therefore checks the deployed image, and after rollback checks every original service definition and desired count before running the workflow again. The regression deliberately makes the waiter succeed while the wrong revision remains selected. Immutable ECR tags must also permit repeated attempts: the release tag combines commit SHA, run ID and attempt, while ECS uses the resolved digest.

Schema rollback and image rollback are different operations. The original old image rejected any unfamiliar schema head. The bridge adds a generic compatibility policy before it becomes the rollback target; migration16 explicitly declares only tested readers for its exact schema head. The old business logic then successfully performs command/idempotency/solve/activation on the expanded database. An unknown future migration still fails readiness. Destructive column changes would need another compatibility phase and data migration; selecting an old image cannot resurrect removed records.

A backup file alone is not restore evidence. The local rehearsal restores into a second disposable database, compares deterministic hashes for every table and runs both current and bridge images against the restored data. It preserves the source application database. The retained dump contains only synthetic records, is ignored by Git and is not a cloud disaster-recovery claim.

Interview practice: explain why the trace parent is transactional; why a UUID metric label is harmful; why a stable deployment can still be the wrong revision; why the unmodified old image fails but the bridge succeeds; and what local Terraform tests cannot establish. Point to the raw incident/release evidence when stating what was actually measured.
